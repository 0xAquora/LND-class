# Texto explicativo

Para hacer esta web del Festival Risco y Voz en Teror he estructurado el código con etiquetas HTML semánticas, una tabla con la programación, listas informativas y un formulario con validaciones conectado a un webhook por POST. También he añadido estilos CSS dentro del propio archivo HTML para ordenar las secciones, mejorar la lectura y adaptar la página a distintos tamaños de pantalla. Todo el avance se ha ido subiendo a GitHub con commits por partes, revisando el código con el validador del W3C y comprobando que llegaban los envíos del formulario. Para resolver dudas durante el trabajo he consultado la documentación de MDN Web Docs sobre HTML y CSS, el validador del W3C (validator.w3.org), la guía de Git y GitHub, Webhook.site para probar el envío y las webs del Ayuntamiento de Teror y de Global Gran Canaria.
